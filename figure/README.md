# Figure Collections

This directory contains figures generated from the downstream analyses.

## Directories

* `1_microbiome_age_model`: Model validation, independent test set results, feature importance, and SHAP value plots.
* `2_separation`: MMI-based stratification plots for individual samples.
* `3_diversity`: Alpha- and beta-diversity plots.
* `4_abundance`: Relative abundance plots.
* `5_ancombc`: Differential abundance analysis plots generated using ANCOM-BC.
* `6_network`: Microbial association network plots generated using NetCoMi and visualized with igraph.
* `6-1_cytoscape`: Microbial association networks visualized using Cytoscape.
* `7_cluster`: Network module heatmaps (source–target) and group comparison dumbbell plots.
