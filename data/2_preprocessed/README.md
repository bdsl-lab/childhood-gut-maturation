## Processed Data Files

Raw sequencing data were processed into amplicon sequence variants (ASVs) and aggregated at the genus level using QIIME2. The processed data include genus-level feature tables and the corresponding representative sequences.

## Directories

* `diversity`: Alpha- and beta-diversity results calculated from the processed data.
* `prv10`: Genus-level feature tables after 10% prevalence filtering and stratification into MMI-based groups.
* `log1p`: Log1p-transformed genus-level feature tables after 10% prevalence filtering and stratification into MMI-based groups.

## Files

* `taxonomy.tsv`: Taxonomic annotation of ASVs.
* `ft.tsv`: Genus-level feature table generated by QIIME2.
* `ab_rel.tsv`: Relative abundance table calculated from the 10% prevalence-filtered genus-level feature table.
