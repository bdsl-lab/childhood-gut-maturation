# Results Data Files

This directory contains the output files generated from the downstream analyses.

## Directories

* `1_statistical`: Statistical analyses of sample metadata and clinical characteristics.
* `2_microbiome_age_model`: Microbial Maturity Index (MMI) predictions generated using a random forest regression model.
* `3_abundance`: Visualization of microbial relative abundance profiles for each sample group.
* `4_ancombc`: Differential abundance analysis performed using ANCOM-BC.
* `5_network_analysis`: Microbial association network analysis performed using SparCC implemented in the NetCoMi package.
* `6_module_analysis`: Identification and analysis of microbial network modules and their relationships.
