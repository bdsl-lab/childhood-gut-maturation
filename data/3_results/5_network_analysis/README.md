# Network analysis files

This directory contains the output files generated from network analyses.

## Directories

- `1_netcomi_inference`: To inferenced networks and networks summary files generated from SparCC by using NetCoMi.
- `2_netcomi_export`: Extract the nodes, edge files of the deduced network, and also extract mean relative abundance information about the nodes of the group.
- `3_netcomi_align`: Align the nodes, edges file extracted by each group into one file.
