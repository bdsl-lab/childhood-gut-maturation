# Microbiome age model results file

This directory contains the output files generated from microbiome age model.

## files

- `italy-mam.joblib`: Model file from which datasets was learned.
- `top30_feature.tsv`: 30 of important feature deduced from the model learning process.
- `model_results.tsv`: File that stores the mmi inferred using the model. Only control samples were used.
- `pibd_results.tsv`: File that stores the mmi inferred using the model. mmi of the PIBD group was predicted using the learned model(`italy-mam.joblib`).
