# Results data files

This directory contains cluster analyses results file.
## Directories
- `1_statistical`: Check for statistical differences in information for sample individuals.
- `2_microbiome_age_model`: Predicted MMI by using Random forest regression algorithm.
- `3_abundance`: Visualizated microbial relative abundance profiles for each sample group.
- `4_ancombc`: To derived features showing statistically significant differences for each group.
- `5_network_analysis`: Microbial interaction network analysis performed using SparCC for use NetCoMi.
- `6_module_analysis`: To determine the relationship between large clusters(module) present in the network.


## Directories
- `corr_counts`: Counting about association counts each group network.

## Files
- `group_cluster_information`: Cluster included node counting each group network.
