# Notebook collections

This directory contains jupyter notebooks used for network inference and network downstream analyses.

## Files
- `1_network_preprocessing.ipynb`: Import feature-table and convert to phyloseq file
- `2_network_inference.ipynb`: Network inference by using NetCoMi.
- `3_network_visualizaion.ipynb`: Using inferred network file, visualized network using at NetCoMi visualized function.
- `4_network_export.ipynb`: Network node and edge tables were exported at this file.
- `5_network_alignment.ipynb`: To visualized at Cytoscape, three of network nodes, edges file consolidated into one node and edge file.
- `6_cluster_analysis.ipynb`: Cluster analysis jupyter notebook.
