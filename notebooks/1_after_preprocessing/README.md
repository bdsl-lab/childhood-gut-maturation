# Notebook collections

This directory contains jupyter notebooks used for preprocessing at genus-level feature table that after QIIME2 export.

## file

- `1-1_normalization.ipynb`: Sample normalization (prv < 10% filtering, log1p normalization)
- `1-2_sample_statistics`: Sample statistical test between sample status group(HC, PIBD)
- `1-1_relative_normalized.ipynb`: To export the relative abundance feature table.
