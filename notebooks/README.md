# Notebook Collections

This directory contains Jupyter notebooks used for data preprocessing and downstream analyses.

## Directories

* `0_sample_process`: Sample exclusion workflow.
* `1_after_preprocessing`: Sample normalization and statistical analyses.
* `2_microbiome_age_model`: Machine learning-based analysis for predicting the Microbial Maturity Index (MMI).
* `3_separation`: Quadratic regression-based stratification of individuals according to the relationship between MMI and chronological age.
* `4_diversity`: Alpha- and beta-diversity analyses.
* `5_abundance`: Relative abundance visualization for each group.
* `6_ancombc`: Differential abundance analysis for each group using ANCOM-BC.
* `7_network`: Workflows for network data preprocessing, association inference, visualization using NetCoMi, node and edge file export, network alignment, and cluster analysis.
